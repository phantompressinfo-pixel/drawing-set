# 05 — BUILDING CODE: which one applies, and the honest limits of this knowledge

## READ THIS BEFORE ANSWERING ANY IBC OR IRC QUESTION

The IBC and IRC are **copyrighted publications of the International Code
Council.** Their full text is **not** in these knowledge files and cannot be.

What **is** in these files is the part that is actual local law: the ordinances
by which Aspen and Pitkin County adopt those codes, **including every local
amendment, deletion, and appendix**, verbatim (files 07 and 10).

**Therefore:**

> **Never quote or paraphrase IBC or IRC section text from memory.**
> You may state **which code and which section number** governs a topic, because
> that is verifiable from the local adopting ordinance and from the code's own
> chapter structure. For the **content** of an ICC section — dimensions,
> minimums, tables, exceptions — say:
> *"I don't have the ICC text. Read §____ in the office's UpCodes subscription
> (upcodes.com) — it shows local amendments merged into the section."*

The office pays for **UpCodes**. That is the licensed reading source; point
people there by default. `codes.iccsafe.org` (free read-only) and the printed
code books are fallbacks.

A confidently wrong egress dimension or guard height on a permit set is exactly
the failure this office cannot afford. Section numbers: yes. Section contents
from memory: never.

Local amendments are different — those **are** in your files and you should quote
them directly, because the local amendment overrides the ICC base text.

## THE JURISDICTIONAL SPLIT — THIS IS THE BIG ONE

**A single-family house is governed by a different code depending on which side
of the city limit line it sits on.**

### City of Aspen — the IRC is NOT adopted

Aspen Municipal Code **§8.16.010** (Ord. No. 01-2023), verbatim:

> "Pursuant to the powers and authority conferred by the laws of the State and
> the Charter of the City, The International Residential Code, 2021 Edition,
> **will not be adopted**."

Aspen Municipal Code **§8.20.010** adopts the **International Building Code,
2021 Edition, including Appendices C, E, and P**, as amended by §8.20.020.

And **§8.20.020(i)**, amending IBC §101.4.11, verbatim:

> "**All references to the International Residential Code (IRC) within this code
> shall be deleted** and the requirement of this code as it pertains to one- and
> two-family dwellings and townhouses shall apply."

**Consequence: in the City of Aspen, a single-family house is designed under the
2021 IBC as amended (Group R-3). There is no occurrence of "R310" anywhere in
Aspen's Title 8.** IRC citations on an Aspen permit set are technically wrong.

Topics that shift as a result:

| Topic | Aspen citation |
|---|---|
| Emergency escape and rescue openings, and area/egress wells | **2021 IBC §1031** (not IRC R310) |
| Covers over area wells | **IBC §1031.6** — bars, grilles, covers, screens and similar devices **are prohibited** over area wells serving emergency escape and rescue openings. A perimeter guard with a gate around the *sides* of a well is a different thing from a cover over the opening |
| Guards | **2021 IBC §1015.2** (where required) and **§1015.3** (height), as amended by Aspen §8.20.020 |

**One real-world nuance to know:** the City's own Model Zoning Submittal example
sheets label light wells with an **IRC R310.2** citation — an IRC reference on a
City-issued example, for a code the City deleted. In practice a *zoning* reviewer
works from that model and does not flag either citation. The zoning portion of
that note (§26.575.020(f)(4)(j)) is what the sheet is actually about. Practical
advice: cite the zoning exception plus IBC §1031, or mirror the model if you want
zero friction — **but do not burn a resubmittal fighting about it.**

### Unincorporated Pitkin County — the IRC IS adopted

Pitkin County Code **§11.20.010**, verbatim:

> "…there is hereby adopted and incorporated herein by reference as if fully set
> forth those regulations contained in by reference thereto, the **International
> Residential Code, 2021 Edition, including Appendices AE, AF, AH AK, and AQ**…"

The County also adopts the **IBC 2021, including Appendices C, E, I and J**
(§11.04.010).

**Consequence: in unincorporated Pitkin County, a single-family house is designed
under the 2021 IRC** — the opposite of the City. IRC citations are correct there.

**So the first question on any building-code question is always: city or county?**
Do not answer until you know.

## HOW TO ANSWER A BUILDING CODE QUESTION — the procedure

0. **Check knowledge file 11 first — the section index.** It maps topics to the
   governing code and section number for both jurisdictions, and lists every
   IBC/IRC section that Aspen or Pitkin amended, with the amendment text. That
   gets the user to the right section without any ICC text. Note its markers:
   ✅ VERIFIED entries are quotable; ⚠️ DRAFT section numbers are pointers only.
1. **Establish the jurisdiction.** City or county. Ask if you don't know.
2. **Search the local title** (file 07 for Aspen, file 10 for Pitkin) for the
   topic. If there is a **local amendment**, it controls — quote it directly.
3. **If there is no local amendment**, name the governing code and section number,
   then send the user to read it in the office's **UpCodes** subscription.
   **Do not supply the text yourself.**
4. **Check the fire district separately.** Fire code is adopted by the fire
   protection district, and wildfire requirements are their own chapter in both
   jurisdictions.
5. **Say which edition you are citing** (2021), and note that editions change.

## THINGS THAT ARE SAFE TO SAY WITHOUT ICC TEXT

Because they come from the local codes in your files, or from the structure of
the codes themselves:

- Which code applies (IBC vs IRC) and why, with the adopting citation
- Which appendices were adopted
- The full text of any **local amendment**
- Which IBC/IRC chapter or section **number** covers a topic
- That a topic is regulated by a code you don't have the text for
- The zoning-side rules — those are entirely in files 06 and 08/09 and can be
  quoted freely

## THINGS TO REFUSE TO ANSWER FROM MEMORY

- Minimum egress opening sizes, sill heights, well dimensions, ladder rules
- Guard and handrail heights, opening limitations, load requirements
- Stair rise/run, headroom, landing dimensions
- Fire separation ratings and assembly requirements
- Insulation R-values and energy compliance paths
- Any table, any exception, any dimension in ICC text

For all of these: **name the section, then send the user to UpCodes.**
