# 03 — CHART TEMPLATES: every chart the submittal needs, blank and ready to fill

Column headings and row lists matched to the City of Aspen's **Complete Model
Zoning Submittal** example set. Copy the structure; fill in the project's own
numbers.

⚠️ **The City's model set contains internal errors** — totals that disagree
between its own sheets, duplicate row labels, a column that does not foot, and
outdated subsection lettering. **Copy its structure, not its arithmetic**, and
match citations to the current code text.

**Rules for every chart below:**
- Every total is a **formula or cell reference**. Never type a result.
- **Show the arithmetic in the adjacent cell** — `(gross × exposed %)`,
  `(deck + steps − exempt)`. This pre-answers "please show your calculations."
- Every exemption row carries its **code citation**.
- Use "N/A" or "None" rather than leaving a cell blank.
- **A floor area legend goes on every page** (the City states this explicitly).

## CHART 10 — HEIGHT OVER TOPOGRAPHY  (Sheet 14)

**For Permit:**

| Elevation Label | Maximum Height | Elevation of Natural Grade | Elevation of Finished Grade | Most Restrictive | Roof Height over Topography | Proposed Roof Height over Most Restrictive |
|---|---|---|---|---|---|---|
| 1 | | | | Natural / Finished | | |
| 2 | | | | | | |
| … | | | | | | |

**For As-Built Survey** (left blank until after construction — usually a CO condition):

| Actual Elevation of Finished Grade | Actual Most Restrictive | Actual Roof Height over Topography | Actual Roof Height over Most Restrictive |
|---|---|---|---|

**What each column actually holds — this is where people go wrong:**

| Column | Contents |
|---|---|
| Maximum Height | the zone district limit — the same on every row unless a documented exception |
| Elevation of Natural Grade | the **ground** elevation at that XY point |
| Elevation of Finished Grade | the **ground** elevation at that XY point |
| Most Restrictive | the **word** "Natural" or "Finished" — whichever elevation is **LOWER**. It flips point to point |
| Roof Height over Topography | the **elevation of the tagged roof measurement point** — a building elevation, not a height |
| Proposed Roof Height over Most Restrictive | the actual height = roof point elevation − the more restrictive grade elevation. **This is the number checked against Maximum Height** |

For a roof point below grade, enter **"N/A – BELOW GRADE"**.

## THE FOUR LEGENDS — do not mix them

| Legend | Entries |
|---|---|
| **ROOF DEMO LEGEND** | EXISTING ROOF TO REMAIN / ROOF TO BE REMOVED |
| **WALL DEMO LEGEND** (reference plans) | EXISTING TO REMAIN / WALL TO DEMOLISH |
| **EXPOSED WALL LEGEND** (wall segment diagrams) | EXISTING WALL TO REMAIN / WALL AREA TO BE REMOVED / **AREA REDUCED FOR FENESTRATION** |
| **SUBGRADE CALCULATIONS LEGEND** | EXPOSED WALL / WALL BELOW GRADE |

On a re-skin project, add separate hatches for: elements demolished · exterior
walls demolished · interior walls demolished · exterior wall material to sheathing ·
exterior siding · roof material to sheathing · floor. If siding replacement is
drawn in the same graphic as demolition, the reviewer will read the whole
building as demolished and comment.

If the project has a prior approval, the demolition legend should match the
approval's exhibit — *"per Resolution __, Series __."*

**Roof plan tags:** MECHANICAL PLATFORM · ROOF VENT · ROOF DRAIN · WASTE VENT ·
`CHIMNEY PROJECTION __' MAX FROM HEIGHT OF BUILDING CONNECTION PER
26.575.020.F.4.A` · T.O. WALL @ PLANTER / DRIVEWAY / PATIO with elevations ·
`FENCE NOT TO EXCEED __' ABOVE FINISH GRADE` · LINE OF EXISTING TOPOGRAPHY ·
LINE OF SETBACK · PROPERTY LINE.

tags with pitch triangles (`1/2 POINT FROM EAVE TO RIDGE`, `1/3 POINT FROM EAVE TO
RIDGE`, `TOP-MOST PORTION`, `RIDGE @ EXISTING ROOF`, `EAVE @ EXISTING ROOF`) each
with its elevation · level datums with elevations.
