# 11 — BUILDING CODE SECTION INDEX (IBC for Aspen · IRC for Pitkin County)

**This file contains no ICC code text.** It tells you *which code and which
section* governs a topic, and — where the local jurisdiction has modified that
section — what the modification says, quoted from the local ordinance.

Use it to go straight to the right section in the office's ICC subscription
(`codes.iccsafe.org`) or code book, instead of hunting.

---

## HOW TO READ THE MARKERS

| Marker | Meaning |
|---|---|
| ✅ **VERIFIED** | Extracted from the local code text in knowledge files 07 (Aspen Title 8) and 10 (Pitkin Title 11). Quote these freely — they are local law and they **override** the ICC base text. |
| ⚠️ **DRAFT** | The ICC section *number* is from general knowledge and has **not** been verified against the ICC text. Treat as a pointer only. **Confirm once against the subscription, then delete this marker.** |

**Never state the contents of a ⚠️ DRAFT section.** Give the number, say it needs
checking, and send the user to the code book. Section content is only safe to
quote when it appears in a ✅ VERIFIED local amendment below.

### The two most-used quotes

✅ **§1031.6 (as adopted by Aspen) — covers over egress wells:** bars, grilles,
covers, screens **and similar devices are not permitted** over area wells serving
emergency escape and rescue openings. A perimeter guard with a gate around the
*sides* of a well is a different thing and is not what this prohibits.

✅ **§101.4.11 (Aspen amendment):** all IRC references deleted; the IBC applies to
one- and two-family dwellings and townhouses.

**Definitions:** ✅ **R202 — "Habitable Space."** The definition stands as
written, with this sentence appended, verbatim:

> *"Unfinished basements with a ceiling height of 80 inches or more are
> considered habitable space."*

**This one matters for county work.** An unfinished basement at 80″+ is habitable
space for building code purposes — which pulls in light, ventilation, egress and
energy requirements. It is a **building code** definition and does not by itself
decide the **zoning** floor area question, but expect it to come up in that
argument. Aspen has no equivalent amendment.

**Design criteria:** ✅ **Table R301.2 replaced** — see Part 5.

**Fire & life safety:** R302.13 (Exception 2 deleted) · **R313.1 and R313.2
(sprinklers)** · R315/R315.1 (CO alarms per Ord. 039-2008)

✅ **R313.1 / R313.2 verbatim thresholds:** an automatic residential fire
sprinkler system is required in structures **3,000 sf or greater in gross floor
area within the Aspen Fire Protection District, and 5,000 sf or greater in all
others** — or two or more stories in height containing four or more dwelling
units. A fire wall does **not** create separate buildings for this purpose.

That threshold catches a lot of Pitkin County houses. Check it early — a
sprinkler system found late is a budget and a water-supply problem, not a
drafting problem.

**Roofs:** ✅ **R902.1** — minimum roof assembly **Class A** (Class B and C
deleted) · ✅ **R903.5 added — snow shed design:** roofs shall be designed so they
do not shed ice and snow onto the main path of egress.

## PART 5 — ✅ VERIFIED: design criteria, and how the two differ

Both jurisdictions replaced the climatic/geographic design criteria table
entirely. **They do not handle snow load the same way** — this is the single most
important difference on this page for a structural sheet.

| | **Aspen — Table 1601.2** | **Pitkin — Table R301.2** |
|---|---|---|
| **Ground snow load** | **100 psf** | **Varies** — use the recommended basic snow load from the **2016 Snow Load Design Data for Colorado** (Structural Engineers Association of Colorado) |
| **Wind** | 89 mph / Exposure B | Engineered per **ASCE 7-10** |
| Seismic design category | C | Varies — per the maps in the 2021 IRC |
| Weathering | Severe | Severe |
| **Frost line depth** | **36″** | **36″** |
| Termite | None to slight | No |
| **Ice barrier required** | **Yes** | **Yes** — per R905.1.2 |
| Flood hazards | See §1612.3 | Latest study |
| Air freezing index | 2,000 | 2,000 |
| Mean annual temp | 40°F | 40.8°F |
| Elevation | 7,820′ | Site specific |
| Altitude correction factor | 0.745 | Site specific |
| Outdoor winter design dry-bulb | **−15°F** | **−16°F** |
| Indoor winter design dry-bulb | 70°F | 70°F |
| Outdoor summer design dry-bulb | 82°F | 82°F |

**A cross-check worth doing while you're in there:** the attic access opening
required by the building code (IBC §1208 / IRC R807) is **not** the same question
as whether an attic is "conveniently accessible" for the zoning floor area
exemption. Providing a code-required hatch does not by itself make an attic
count. Keep the two analyses separate — the zoning rule is §26.575.020(d)(4) and
it turns on finish and access *method*, not on whether an opening exists.
