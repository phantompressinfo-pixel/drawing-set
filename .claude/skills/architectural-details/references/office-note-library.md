# Office note library - wording taken from the office's issued details

Transcribed from the 22 sample sheets the office supplied (A6.01-A6.03, A6.08,
A6.11, A6.13, A6.16-A6.18, A6.20-A6.22, A6.32-A6.38). **Use this wording first.**
Write new wording only when no line here fits, and keep it in the same voice.

Placeholders: `__` means a value to fill, and `[..]` means pick one option.

## Voice and abbreviations

- **Style**
  - ALL CAPS.
  - Short noun phrase first, then a dash and the instruction: `COPPER SHT. METAL
    FLASHING PAN - RETURN UP @ JAMBS 6" MIN.`
  - Pointers to other drawings end the note: `- SEE WATERPROOFING DRAWINGS`.
- **What's already covered elsewhere.** Items owned by a schedule or another
  discipline are named and pointed, never specified:
  - `WINDOW PER SCHEDULE`
  - `STL. BEAM, S.S.D.`
  - `FINISH PER SCHEDULE`
  - `ROLLER SHADE AS SCHEDULED, SEE LOW VOLTAGE`
- **"AS REQ."** is used only to hand framing and blocking to the GC:
  - `FRAMING AS REQ.`
  - `BLOCKING AS REQUIRED`
  - `2X WOOD BLOCKING AS REQ'D`
- **Waterproofing.** The building-envelope / waterproofing consultant owns the
  weather barrier, flashings, sealants and waterproofing. The details show the
  intent and point to them: `SEE WATERPROOFING DRAWINGS`, `PER BUILDING ENVELOPE
  CONSULTANT`, `REFER TO WP DRAWINGS FOR WATERPROOFING INSTALLATION`.

## Lines the checker will question

These appear on the sample set. Fix them before reusing them:

| Line on the sample set | Problem | Use instead |
|---|---|---|
| `... NOT MORE THAN 38 INCHES PER IRC R311.7.7.1` (A6.34, A6.38) | R311.7.7.1 does not exist in the 2021 IRC. Handrail height is **R311.7.8.1**. On a City of Aspen project, no IRC section applies at all: the City did not adopt the IRC, so use **IBC 1014.2**. | `... PER IRC R311.7.8.1` (Pitkin County) or `... PER IBC 1014.2` (City of Aspen) |
| `AIR SEALING PER 2015 IECC (R402.4.1.1)` (general note 3) | Aspen (M.C. 8.46.030) and Pitkin County (Title 11.32) have both adopted the **2021** IECC | `AIR SEALING PER 2021 IECC R402.4.1.1`. Confirm the section in the 2021 IECC before issue; the IECC is not in the code library dataset. |
| `REFER TO DETAIL  FOR WINDOW SURROUNDS ...` (general note 5) | The detail number is blank on every sheet | Fill in the number and sheet |
| `CAP RAIL VINYL, BLACK, BY CRL OR EQUAL` (A6.38) | "OR EQUAL" opens a substitution | Keep it only if substitution is intended |
