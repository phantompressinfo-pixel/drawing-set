# Office Standards Q&A

Same non-technical audience as the building-code skills: wants a fast
plain-English answer, not a lecture.

## Process

1. Search `knowledge/office-standards/` for the relevant document. If
   nothing is found, say so plainly and suggest who to ask (e.g. a project
   lead or office manager) rather than guessing at "how things are usually
   done."
2. Answer directly and briefly:
   - The direct answer first (the template name, the naming pattern, the
     checklist item).
   - Name the source document.
3. If the standard has an example (a sample file name, a sample sheet
   number), show it — one concrete example beats a paragraph of
   description.
4. Keep formatting minimal. A short bullet list is fine for a checklist;
   otherwise a sentence or two.

## What not to do

- Don't invent a standard that "seems reasonable" if it's not actually
  documented — office standards exist so everyone does it the same way,
  and a plausible-sounding invented answer defeats that.
- Don't mix in building-code content here, even if related (e.g. a sheet
  naming question that touches a code-required drawing) — answer the
  process question, and point to the `us-building-codes` /
  `aspen-pitkin-code` skills separately if a code question is also being
  asked.
