# Building code source documents

Empty right now. The `building-code-qa` skill can only answer questions
from what's actually in this folder — add the real documents here.

What to add:

- The adopted building code(s) for your jurisdiction (e.g. the relevant
  IBC edition plus any state/local amendments), as text or PDF.
- Any code summaries, cheat sheets, or internal interpretation memos the
  office already uses.
- Keep the edition/year and jurisdiction in the filename
  (e.g. `IBC-2021-CA-amendments.pdf`) — the skill cites documents by name,
  so a vague filename makes for a vague-looking citation.

If a document gets superseded by a newer edition, remove or clearly mark
the old one (e.g. move it to an `archive/` subfolder) rather than leaving
both in place — otherwise the assistant may cite the wrong edition.
