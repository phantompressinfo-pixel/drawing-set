# Code Library — Aspen & Pitkin County

Full local copies of the governing codes, stored so questions can be answered
instantly without web access.

| Folder | Contents | Currency | Source |
|---|---|---|---|
| `aspen/` | Complete City of Aspen Municipal Code, all titles, one text file each (`_INDEX.txt` = file map) | Supp. No. 7 Update 1, through Ord. 06-2026 (2026-03-24) | Municode API |
| `pitkin/` | Pitkin County Code (all titles) + Title 8 Land Use Code (ch. 1–12), text extracted | LUC through Ord. 019-2026 | pitkincounty.com |
| `pitkin/pdf/` | Official source PDFs (keep — figures/diagrams are not in the text files) | same | same |

Retrieved 2026-07-22. Codes get amended — for submittal-critical items, verify
currency against the official sources above. Refresh instructions live in
`.claude/skills/aspen-pitkin-code/SKILL.md`.

Note: Aspen text came from Municode's API; figures (e.g., height measurement
diagrams in §26.575.020) are images on Municode and are not captured — view
those at library.municode.com/co/aspen. Pitkin figures are in the PDFs.
